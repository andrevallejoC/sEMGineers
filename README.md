# EMG Analysis — Trunk Stabilizer Muscles

**Bilateral Activation and Asymmetry of Trunk Stabilizer Muscles During a Public Transportation Simulation: A Pilot Study Using Surface Electromyography**

University Project — Introduction to Biomedical Signals

---

## Description

An interactive **Streamlit** web application for visualizing and analyzing surface electromyography (sEMG) signals recorded from the **right and left upper trapezius muscles** using the **BITalino** biosignal acquisition platform and **OpenSignals** software.

The application supports the analysis of three experimental conditions designed to simulate standing balance during public transportation:

* **Baseline**
* **Single Hand Strap**
* **Double Hand Strap**

## Expected Data Format

Each OpenSignals-exported `.txt` file must follow the naming convention:

```text
<condition>_trapezius_<participant>.txt
```

Examples:

```text
baseline_trapezius_andre.txt
single_strap_trapezius_alex.txt
double_strap_trapezius_sandro.txt
```

All files must be placed inside the `Datos/` directory.

The application automatically ignores the first three header lines generated by OpenSignals and extracts the following analog channels:

* **A1** → Right Upper Trapezius
* **A2** → Left Upper Trapezius

Sampling frequency:

* **1000 Hz**

## Main Features

* **Recording Selection**

  * Load participant recordings and experimental conditions on demand.

* **Automatic ADC-to-millivolt (mV) Conversion**

  * Raw BITalino ADC values are automatically converted into millivolts using the standard PLUX/OpenSignals conversion equation. All visualizations, statistics, and exported results are expressed in physical units (mV).

* **Interactive Time Window Selection**

  * Analyze any desired segment of the recording using an interactive slider. Every visualization, statistical metric, and spectral analysis is recalculated for the selected interval.

* **Interactive Visualization**

  * Individual visualization of right and left channels.
  * Synchronized comparison with shared zoom and navigation.
  * Built with Plotly.

* **Configurable Signal Processing**

  * Full-wave rectification.
  * Adjustable Butterworth band-pass filter.
  * 60 Hz notch filter for power-line interference removal.

* **Baseline Normalization**

  * Signal amplitudes can be normalized as a percentage of the RMS obtained during the participant's Baseline recording.

* **Descriptive Statistics**

  * Mean
  * Median
  * Standard Deviation
  * Maximum
  * Minimum
  * RMS
  * Mean Absolute Value (MAV)
  * Variance
  * Signal Energy

* **Bilateral Asymmetry Assessment**

  * Dedicated dashboard including:

    * Gauge indicator
    * Bilateral RMS comparison
    * Automatic interpretation:

      * Normal Symmetry
      * Mild Asymmetry
      * Moderate Asymmetry
      * Severe Asymmetry

* **Spectral Analysis**

  * Fast Fourier Transform (FFT)
  * Welch Power Spectral Density (PSD)
  * Short-Time Fourier Transform (STFT) Spectrogram

* **CSV Export**

  * Export processed statistics and summary metrics for the selected analysis interval.

## Technical Notes

* The application follows a modular software architecture with no mutable global variables. Configuration parameters are centralized in `config.py`, while user interaction is managed through Streamlit's `st.session_state`.

* Digital filtering is implemented using `scipy.signal`, employing second-order sections (`sosfiltfilt`) to ensure numerical stability and zero-phase filtering.

* Spectral analysis is performed using:

  * `numpy.fft`
  * `scipy.signal.welch`
  * `scipy.signal.spectrogram`

* ADC-to-millivolt conversion is based on the BITalino ADC resolution, reference voltage, and EMG amplifier gain, all configurable within `config.py`.
